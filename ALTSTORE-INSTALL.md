# Безкоштовна пробна інсталяція

Мета: перевірити власний застосунок на одному iPhone без оплати Apple Developer Program.

## Файл застосунку

Після успішного запуску GitHub Actions завантажте artifact `Atelier-iPhone-unsigned`, розпакуйте ZIP і отримайте `Atelier-unsigned.ipa`. Це збірка для фізичного iPhone, не симулятора. Вона ще не підписана: її має підписати AltStore для вашого Apple Account. Просте відкриття IPA у Files не встановлює застосунок.

Мінімальна система — iOS 17. Сумісність із вашим телефоном і підписанням ще потрібно перевірити; успішне збирання IPA не означає успішного встановлення.

## Початкове налаштування

1. Використовуйте **AltStore Classic / AltServer для Windows**, а не AltStore PAL. Офіційний сайт: https://altstore.io/ .
2. Дотримуйтеся актуальної офіційної інструкції для Windows: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows . Вона описує необхідні компоненти Apple, підключення iPhone кабелем і встановлення AltStore.
3. Введення Apple Account, пароля, підтвердження входу, довіру пристрою й Developer Mode виконує власник телефона самостійно. Не надсилайте пароль у чат і не додавайте його в GitHub.
4. Коли AltStore відкривається на iPhone, відкрийте My Apps → «+» → виберіть `Atelier-unsigned.ipa`. Телефон і AltServer повинні мати з’єднання згідно з інструкцією AltStore.
5. Після встановлення виконайте сценарії з `ACCEPTANCE.md`, спочатку на пробних записах.

## Поновлення

Безкоштовний підпис діє 7 днів. Поновлюйте його через AltStore/AltServer до закінчення строку. Якщо він минув, поновіть підпис; не видаляйте застосунок із даними для «перевстановлення». Перед оновленням зробіть зашифровану резервну копію. Інструкція поновлення: https://faq.altstore.io/altstore-classic/your-altstore .

Цей спосіб потребує періодичного обслуговування й не є постійною інсталяцією через App Store. На даному етапі перевірено тільки хмарне збирання; реальну інсталяцію ще не підтверджено.
