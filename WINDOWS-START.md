# Початок із Windows

## Що вже готово

У `.github/workflows/ios.yml` є автоматична перевірка на хмарному Mac. Вона лише збирає код і запускає тести. Вона не встановлює застосунок на iPhone та не завантажує його в TestFlight.

## GitHub

1. Якщо немає облікового запису: відкрийте https://github.com/signup та зареєструйтеся.
2. Створіть окремий репозиторій, наприклад `atelier-ios`. Для закритого коду виберіть **Private**.
3. Завантажте в корінь репозиторію вміст папки `atelier`, а не всю папку верхнім рівнем. У корені повинні бути `project.yml`, `Sources`, `Tests` і `.github`.
4. Якщо завантажуєте через браузер і папку `.github` пропущено: Create new file → назва `.github/workflows/ios.yml` → вставте вміст однойменного локального файлу → Commit changes.
5. Відкрийте вкладку **Actions** → «Перевірка Ательє для iPhone». Після завантаження запуск починається автоматично; повторний запуск доступний через **Run workflow**.
6. Якщо перевірка червона: відкрийте невдалий крок і передайте його журнал для виправлення. Якщо зелена — код пройшов збирання та автоматичні тести в симуляторі; реальний iPhone ще потрібно перевірити.

Приватні репозиторії мають квоту хмарних запусків залежно від тарифу GitHub. Перед платним використанням перевірте Billing; для першого запуску не потрібно налаштовувати Apple-сертифікати.

## Установлення на iPhone

Для обраного шляху через TestFlight наступним окремим етапом потрібні Apple Developer Program, налаштування App Store Connect і підписання збірки. Реєстрацію можна відкласти до успішної перевірки коду. Особистий Mac для хмарного підписання й завантаження не обов’язковий.

У цьому проєкті ще немає налаштованого завантаження в TestFlight. Не додавайте паролі Apple або ключі підписання у вихідний код.
