# Ательє 1.0

Автономний застосунок iPhone українською мовою. Усі суми — цілі гривні. Принтер та QR заплановані для наступного оновлення.

## Збирання

Потрібні macOS, Xcode 16 або новіший та XcodeGen. Мінімальна версія iOS — 17.

```sh
brew install xcodegen
cd atelier
xcodegen generate
open Atelier.xcodeproj
```

У Xcode виберіть власну Apple Developer Team, змініть bundle identifier за потреби та запустіть на iPhone. Для TestFlight: Product → Archive → Distribute App → App Store Connect. Підписання потребує вашого облікового запису Apple; вихідний код не містить сертифікатів.

Проєкт уже завантажено в [sanrvua-cpu/Ol](https://github.com/sanrvua-cpu/Ol). Конфігурація хмарної перевірки лежить у `.github/workflows/ios.yml`. Workflow збирає й запускає тести в симуляторі без підписання. [Перша перевірка 12 жовтня 2026](https://github.com/sanrvua-cpu/Ol/actions/runs/38215527496) завершилася успішно: Xcode 16.4, симулятор iPhone 16 Pro, iOS 18.5, 5 тестів без помилок. Власний Mac і Apple Developer Program для цього запуску не потрібні. Завантаження в TestFlight ще не налаштовано.

У Xcode запустіть Product → Test. П’ять тестів перевіряють збереження/дублювання, нумерацію після кошика, часткову видачу, відхилення некоректної зміни та шифрування/відновлення. Вони вже пройшли на хмарному Mac; Windows використовується для редагування та передавання коду.

## Реалізовано

- Клієнти, пошук, кілька речей і робіт, ручні номери бірок.
- Автоматичні чернетки, прайс, терміни та календар за датами.
- Стани, групова зміна, безпечне скасування, часткова видача з боргом.
- Оплати, попередження про дублювання, історія виправлень, повернення, витрати.
- Швидкий ремонт, підсумки дня/тижня/місяця/року.
- Кошик без автоматичного очищення.
- SQLite з транзакціями, UUID, керованою версією схеми.
- Зашифрований експорт та відновлення з паролем через Files.
- Блокування через системну біометрію або код iPhone.

## Межі поточної версії

Код створено на Windows, збирання та автоматичні тести підтверджено на хмарному Mac. Інтерфейс, апаратні функції й перенесення копії між реальними iPhone ще потребують перевірки; це не підписаний файл для встановлення. Власний PIN застосунку, імпорт контактів і SMS-композер не входять у цей початковий випуск. Дзвінок доступний із картки клієнта. Аванс враховується в замовленні; перенесення переплати між замовленнями відкладено. Нагадування про копію показується всередині застосунку. Друк та камера не реалізовані.

Див. `ACCEPTANCE.md` для перевірки перед реальним використанням.
