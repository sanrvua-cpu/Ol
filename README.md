# Ательє 1.0

Автономний застосунок iPhone українською мовою. Усі суми — цілі гривні. Принтер та QR заплановані для наступного оновлення.

## Збирання

Потрібні macOS, Xcode 16 або новіший та XcodeGen. Мінімальна версія iOS — 17.

```sh
brew install xcodegen
cd atelier
xcodegen generate
open Atelier.xcodeproj
```

У Xcode виберіть власну Apple Developer Team, змініть bundle identifier за потреби та запустіть на iPhone. Для TestFlight: Product → Archive → Distribute App → App Store Connect. Підписання потребує вашого облікового запису Apple; вихідний код не містить сертифікатів.

Для хмарної перевірки через GitHub Actions завантажте **вміст** папки `atelier` у корінь окремого репозиторію, включно з прихованою папкою `.github`. Конфігурація вже лежить у `.github/workflows/ios.yml`. Workflow збирає й запускає тести в симуляторі без підписання. Його ще не запускали. Завантаження в TestFlight налаштовується окремо після успішного збирання. Власний Mac і Apple Developer Program для цього запуску не потрібні.

У Xcode запустіть Product → Test. П’ять тестів перевіряють збереження/дублювання, нумерацію після кошика, часткову видачу, відхилення некоректної зміни та шифрування/відновлення. На Windows ці тести не виконувалися.

## Реалізовано

- Клієнти, пошук, кілька речей і робіт, ручні номери бірок.
- Автоматичні чернетки, прайс, терміни та календар за датами.
- Стани, групова зміна, безпечне скасування, часткова видача з боргом.
- Оплати, попередження про дублювання, історія виправлень, повернення, витрати.
- Швидкий ремонт, підсумки дня/тижня/місяця/року.
- Кошик без автоматичного очищення.
- SQLite з транзакціями, UUID, керованою версією схеми.
- Зашифрований експорт та відновлення з паролем через Files.
- Блокування через системну біометрію або код iPhone.

## Межі поточної версії

Код створено на Windows. Збирання, UI та апаратні функції ще потребують перевірки в Xcode й на iPhone; це не готовий файл для встановлення. Власний PIN застосунку, імпорт контактів і SMS-композер не входять у цей початковий випуск. Дзвінок доступний із картки клієнта. Аванс враховується в замовленні; перенесення переплати між замовленнями відкладено. Нагадування про копію показується всередині застосунку. Друк та камера не реалізовані.

Див. `ACCEPTANCE.md` для перевірки перед реальним використанням.
